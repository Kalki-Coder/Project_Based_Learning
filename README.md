## 🚀 How to Run These Projects

Most projects here are separated into their own folders. To run a specific project:

1.  **Clone the repo:**
    ```bash
    git clone [https://github.com/Kalki-Coder/Random-Shit.git](https://github.com/Kalki-Coder/Random-Shit.git)
    ```
2.  **Navigate to the project folder:**
    ```bash
    cd project-folder-name
    ```
3.  **Install dependencies (Check the specific folder's README):**
    ```bash
    npm install
    # or
    yarn install
    ```
4.  **Start the server:**
    ```bash
    npm start
    ```
